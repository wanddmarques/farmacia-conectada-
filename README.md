Aplicação web desenvolvida com HTML e CSS, criada para representar uma interface moderna e responsiva de uma farmácia online, facilitando a visualização de produtos, informações e serviços farmacêuticos.

O projeto Farmácia Conectada foi desenvolvido com foco em praticar:

Estruturação de páginas web
Estilização moderna com CSS
Organização de layout responsivo
Experiência visual para aplicações de saúde
Criação de interfaces intuitivas

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

HTML semântico
Flexbox
Responsividade
Organização de arquivos
Design de interfaces
Estrutura visual moderna
